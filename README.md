# Topology-Notes-Chinese
这是[Stefan Friedl](https://friedl.app.uni-regensburg.de/index.html)的拓扑学笔记的中文翻译, 目前使用的是 **1t-total-public-august-20.pdf**, 翻译完前九部分.

原书版本的下载地址在[这里](https://github.com/lolisix/Topology-Notes-Chinese/releases/tag/%E5%8E%9F%E4%B9%A6)

本文档使用的是mathpix识别pdf为tex格式, 并由deepseek进行翻译.

## 本书缺陷
由于mathpix识别不了 `tikz` 图, 因此本文档中大量的图不是矢量图, 是低分辨率的位图.

不过我可以手动把图表交换的图用 `tikz-cd` 环境写出, 你可以告诉我本文中哪个地方没有进行修改. 不过其他的 `tikz` 图就不用反馈了, 因为我不会画 `tikz` 图, 而 ChatGPT 6 luna 绘制的效果也不太好. (我穷, 买不起ClosedSI的订阅, 而deepseek的识别效果也不太好.)

由于原书中使用了大量的位于同一排图, 但是mathpix可能并没有把他们当作一个图片处理, 因此会出现原本在同一排的图, 在翻译版里是竖向排列的. 这种问题你也可以想我反馈.

原书中对大量的公式进行了注释, 但是这个地方只能人工来处理, 有哪个地方的注释的行间距过大、或是过小, 有哪个地方原本有注释, 翻译版却没了注释, 都可以反馈给我. 这里, 我使用的是宏包 `annotate-equations` 进行注释.

其他问题你也可以反馈给我.

## 待求解的问题
由于这本书目前还在更新, 并且作者致力于把前面的章节编写得更加易懂, 因此作者的更新中会有很多「破坏性更新」, 比如在某个部分里增加新章节, 或是把某个章节拆成两章, 等等. 由于我不知道作者的源代码, 因此没法通过比较新老代码来获取增量信息, 从而进一步判断哪些章节应该新翻译, 哪些章节不用. 

目前只能通过分析新老 `.pdf` 的目录书签文件, 来判断哪些章节 **可能** 需要新翻译, 哪些章节不需要, 读者能不能帮我想想, 用什么样的章节管理方式, 可以更好地应对这种「破坏性更新」? 又可以通过哪些方式, 可以获取哪些章节应该重新翻译、哪些不需要?
